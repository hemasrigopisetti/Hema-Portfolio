# 🌟 Hemasri Gopisetti — Personal Portfolio

A sleek, dark-themed personal portfolio website built with pure **HTML5, CSS3, and JavaScript**. Features animated particles, smooth scroll reveals, typing effects, and a fully responsive design.

🔗 **Live Demo:** [hemasrigopisetti.github.io/Hema-Portfolio](https://hemasrigopisetti.github.io/Hema-Portfolio/)

---

## ✨ Features

- ⚡ Animated particle background using Canvas API
- 🖱️ Custom gold cursor with magnetic ring effect
- ⌨️ Typewriter role animation in Hero section
- 🎞️ Scroll-reveal animations on all sections
- 📱 Fully responsive (mobile, tablet, desktop)
- 🌑 Elegant dark theme with gold accents
- 🔵 Fixed dot-navigation with section labels
- 📬 Contact form with simulated send feedback

## 🚀 How to Deploy on GitHub Pages

1. **Create a new repository** named `My-Portfolio` on GitHub
2. **Upload** all the files keeping the folder structure intact
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)`
5. Click **Save** — your site will be live at:
   `https://yourusername.github.io/My-Portfolio`
